# 周邊設備設定：掃描槍、發票機、點陣印表機、展場平板

系統是網頁，周邊設備都透過「電腦 / 平板的系統」連接，不用另外裝驅動程式到 ERP 裡。

---

## 1. 掃描槍（條碼槍）

**適用**：一般 USB 或藍牙條碼槍（鍵盤模式，大部分出廠預設就是）。

1. 插上 USB（或藍牙配對）。打開記事本嗶一下，看到數字出現、而且會自動換行，就代表可以用。
   - 如果沒有換行：照掃描槍說明書掃「Enter / CR 後綴」的設定條碼。
2. 品項主檔要填 **條碼**（「品項與 BOM」→ 品項 → 條碼）。沒有條碼的也可以掃料號。

**在哪裡用**

| 畫面 | 怎麼用 |
| --- | --- |
| **掃碼銷貨**（銷售 → 掃碼銷貨） | 選客戶 → 嗶商品（同一個嗶兩次 = 2 件）→「建立銷貨單」。一次產生訂單、出貨單（銷貨單）、應收與發票，並可直接列印 |
| **收銀台** | 不用點任何地方，直接嗶就加進購物車 |
| 銷售訂單、報價單、採購單 | 表單上方有掃描框，嗶一下加一列 |

## 2. 發票機（電子發票證明聯）

**適用**：58mm 熱感出單機，例如 EPSON TM-T82III、TM-T88、芯燁 XP-58 等，要有 Windows / macOS 印表機驅動。

1. 照印表機廠商說明安裝驅動，在電腦的「印表機」裡看得到它。
2. 印表機的紙張大小設成 **58mm（或 57mm）× 連續紙**。
3. 系統設定（使用者與權限 → 系統設定）填好：
   - **公司統編**：印在「賣方」。
   - **發票字軌**、**下一張發票號碼**：依財政部配發的字軌號碼。
   - **電子發票 QR Code 金鑰**：財政部電子發票平台核發的 32 碼金鑰。沒填的話 QR Code 的驗證欄位會印 *，消費者 App 驗證會失敗。
4. 收銀台結帳後按 **「印發票」**；批發的應收帳款在「會計 → 應收帳款 → 發票」。
5. 第一次列印時在瀏覽器的列印視窗選這台發票機、邊界選「無」，Chrome 會記住。

**證明聯內容**：公司名稱、電子發票證明聯、期別（例：115年11-12月）、發票號碼、日期時間、隨機碼、總計、賣方統編（有統編的買方會印買方統編、銷售額、稅額）、一維條碼、左右兩個 QR Code，下方附交易明細。

**不想每次跳出列印視窗**：Chrome 捷徑加上 `--kiosk-printing` 參數，會直接印到預設印表機（收銀機建議這樣設）。

> **注意：上傳財政部還沒有做。** 系統負責「印出符合格式的證明聯」與「依字軌編號」。開立的發票要在 48 小時內上傳到財政部電子發票平台，需要再串接加值服務中心（例如綠界、藍新、ezPay）或財政部 Turnkey。有帳號後可以再接上。
> 收銀機日結時會列出這一班**沒有用到的發票號碼**，要依規定申報空白發票。

## 3. 點陣印表機（三聯單）

**適用**：EPSON LQ-310、LQ-690C 等點陣（點針）印表機，搭配「中一刀」連續報表紙（9.5 × 5.5 吋，三聯複寫）。

1. 安裝印表機驅動。在電腦的印表機「喜好設定 → 紙張」新增自訂紙張 **241 × 140mm**（中一刀）並設為預設。
2. 單據列印畫面右上角選紙張 **「中一刀三聯單（點陣印表機）」**，再按列印。
   - 出貨單（銷貨單）可以直接按 **「三聯單（點陣）」**。
   - 所有 A4 單據都可以切換成中一刀，內容較多會自動接到下一張。
3. 列印視窗選點陣印表機、邊界「無」、縮放 100%。
4. 第一張對齊：調整印表機的撕紙位置，讓單據標題對準報表紙第一行。

## 4. 展場無線 POS（平板 / 手機）

**需要**：雲端版（Supabase）、平板或手機（建議 Android 平板或 iPad，Chrome / Safari）、藍牙掃描槍、藍牙或 Wi-Fi 出單機（選用）。

### 出發前（在公司、有網路時）
1. **建一個展場儲位**：倉儲管理 → 倉庫與儲位設定 → 新增倉庫，種類選 **「門市」**，例如「展場」，儲位「EXPO-1」。
2. **調撥展場要賣的貨**：倉儲管理 → 調撥 / 補貨到門市 → 從成品倉調到展場儲位。
3. **（選用）建促銷活動**：價格表與促銷 → 促銷活動 → 設定展覽期間的門市活動價，期間內自動套用。
4. **每台平板先上線打開一次**：登入 → 收銀台 → 右上角選 **收銀機代號**（A、B、C…，每台不同）→ 選展場儲位 → **開始營業**。
   - 開班時會先保留一段發票號碼給這台機器（預設 100 張，可在系統設定改），斷線也能繼續開發票、不會跟別台重號。
   - 瀏覽器選「加到主畫面」，之後像 App 一樣打開。

### 展場現場
- 網路斷掉也可以照常結帳。右上角會顯示 **「離線中・N 筆待上傳」**，網路恢復後自動上傳，變回「已同步」。
- 斷網時關掉、重開網頁也沒關係，資料存在平板上。
- 平板不要清除瀏覽器資料，也不要在還有「待上傳」時登出。

### 收攤後
1. 確認每台都顯示 **「已同步」**。
2. 各台按 **日結** 點現金，日結會列出沒用到的發票號碼。
3. 剩下的貨用調撥調回成品倉。

### 如果出現「上傳失敗」
可能是離線期間兩台賣了同一批最後幾件，雲端庫存不夠。點右上角的紅色提示 → 看是哪一筆：
- 補調撥庫存到展場儲位後按 **「全部重試」**；或
- 確定那筆不要了（例如已經人工退款）再按 **「捨棄」**。
