# 可列印表單清單：與 ERP 常見表單對照

依一般製造業 ERP（鼎新、正航、SAP B1 等）常見的列印表單逐項對照。
全部在「表單列印」頁，或單據頁面上的「🖨 列印」按鈕。

圖例：✅ 有　🆕 這次新增　❌ 沒有

## 列印格式檢查

每次修改都用自動測試把每一種表單實際印成 PDF 檢查：

- A4 單據都是 A4 尺寸。內容一頁放得下的就只印一頁，簽名欄在頁底；放不下的自動分頁，表頭每頁重複。
- 沒有任何表格或文字超出紙張右邊、下緣，也沒有文字被截斷。
- 批號標籤、出貨嘜頭是 100×70mm，每張一頁。
- 門市收據寬 58mm，長度依內容。
- 數字靠右對齊、不換行；金額依千分位顯示，負數有負號，不會出現「-0」。
