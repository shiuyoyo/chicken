# 操作說明（簡易版）

給老闆 / 管理者自己看的。只寫最常用的，細節照畫面上的提示操作即可。

---

## 1. 登入

- **雲端版**（正式上線後）：打開網址 → 輸入 Email 和密碼。
  第一次用：按「第一次使用？設定密碼」→ 到信箱點確認信 → 回來登入。
- **本機版**（示範網頁）：點自己的名字 → 輸入 PIN。示範帳號：王老闆 `0000`。

右上角可以切換：
- **標準**：選單＋表單，辦公室用。
- **大按鈕**：一排一個大框框（進貨、領料投料、產出、出貨、品管、收銀），現場用手機點。

---

## 2. 第一次上線要做的事（只做一次）

1. **系統設定**：「使用者與權限 → 系統設定」填公司名稱、統編、地址、電話，以及各種門檻（採購多少要核准、調整多少要核准…）。
2. **倉庫與儲位**：「倉儲管理 → 倉庫與儲位設定」。
3. **品項**：「品項與 BOM」建立原料、包材 / 零件、半成品、成品。
   - 成品、半成品要設 **BOM**（用哪些料、每個用多少）。
   - 同一款不同口味 / 顏色：打開品項 → 按「建立變化款」，一次開好多個料號。
4. **客戶、供應商**：「客戶」「供應商」。
5. **員工**：「使用者與權限」新增員工、選角色、填 **Email**（雲端版員工用這個 Email 登入）。

---

## 3. 每天的流程

```
接單 → 缺料就採購 → 進貨 → 開工單 → 領料 → 投料 → 產出 → 品管 → 出貨 → 開發票 → 收款
```

| 要做的事 | 去哪裡 | 怎麼做 |
| --- | --- | --- |
| 接訂單 | 銷售訂單 → ＋ 新訂單 | 選客戶、品項、數量。超過信用額度或低於底價會自動送主管核准 |
| 看缺什麼料 | 銷售訂單 → 點訂單 | 「原料需求」會列出缺料 → 按「產生採購單」 |
| 開工單 | 同一張訂單按「依訂單開工單」 | 有半成品不夠時，會自動先開半成品工單 |
| 採購 | 採購單 → ＋ 新採購單 | 超過金額門檻會自動送核准 |
| 進貨 | 大按鈕「進貨」或「進貨」頁 | 選採購單 → 輸入數量。需要檢驗的料要品管合格才能用 |
| 生產 | 大按鈕「領料 / 投料」「產出」，或「生產工單」 | 選工單 → 領料 → 投料 → 產出 |
| 品管 | 大按鈕「品管」或「品管 QC」 | 合格才能出貨 |
| 出貨 | 大按鈕「出貨」或「出貨」頁 | 系統自動挑先到期的批號、算箱數 |
| 開發票 / 應收 | 出貨單 → 「開立發票 / 應收」 | |
| 收款 / 付款 | 會計 → 應收帳款 / 應付帳款 | 按「收款」「付款」 |

**看一張訂單做到哪了**：「訂單進度」，接單到收款 8 個階段一目了然。

## 4. 簽核（你最常要做的）

- 有東西等你核准時，右上角會顯示「待簽 N」。
- 到「簽核中心」→「待我核准」→ 按 **核准** 或 **退回**（退回要寫原因）。
- 每筆都可以按「簽核單」列印。
- 申請人不能核准自己的申請。

會送簽核的：大額採購、超過信用額度或低於底價的訂單、大額庫存調整 / 盤差、客戶退貨、門市作廢、品管改判合格。

---

## 5. 列印

- 單據頁面上的「🖨 列印」，或左邊「表單列印」找所有表單。
- 按「列印 / 存 PDF」→ 選印表機，或選「另存為 PDF」。
- 常用：報價單、訂單、採購單、出貨單、揀貨單、出貨嘜頭（每箱一張）、製令單、BOM 表、批號標籤、對帳單、簽核單、試算表、損益表、庫存明細表。

---

## 6. 倉庫

| 要做的事 | 去哪裡 |
| --- | --- |
| 看庫存 | 倉儲管理 → 庫存（可用 = 品管合格且沒過期） |
| 補貨到門市 / 移倉 | 倉儲管理 → 調撥 / 補貨到門市 |
| 報廢、破損 | 倉儲管理 → 庫存調整（金額大的要核准） |
| 盤點 | 倉儲管理 → 盤點 → 選倉庫 → 產生盤點單 → 填實盤數 → 送出過帳 |
| 快到期的 | 倉儲管理 → 效期管理 |
| 出問題要召回 | 批號追溯 → 輸入批號 → 看用到哪些料、賣給哪些客戶 |

---

## 7. 門市

- 收銀員：「收銀台」→ 開班 → 點商品 → 結帳 → 下班前按「日結」點現金。
- 門市只能賣「門市儲位有庫存」的東西，沒貨就從倉庫調撥過去。

---

## 8. 月底

1. 「會計 → 月結關帳」看檢查項目（未簽核、未結案工單、未日結…）。
2. 都處理好 → 選日期 → 關帳。關帳後那段日期不能再改帳。
3. 「經營報表」看銷售、毛利；「會計」印損益表、試算表、帳齡表。

---

## 9. LINE 通知

- 員工加官方帳號 → 在 LINE 裡選自己的職位 → 你到「LINE 通知 → 綁定申請」按確定。
- 之後有新訂單、要核准、品管不合格、低庫存…會自動傳 LINE。
- 哪些事通知哪些職位，在「LINE 通知 → 通知規則」改。
- 設定方式見 [line-setup.md](line-setup.md)。

---

## 10. 員工管理

- **新員工**：使用者與權限 → 新增使用者 → 填姓名、角色、Email。
- **離職**：打開那位員工 → 取消「啟用」→ 儲存。立刻不能登入。
- **權限**：使用者與權限 → 角色權限，每個功能設「無 / 檢視 / 編輯 / 核准」。

---

## 11. 常見問題

| 狀況 | 原因 / 解法 |
| --- | --- |
| 員工說「還沒有開通」 | 到「使用者與權限」幫他填上他登入用的 Email |
| 收不到確認信 / 重設密碼信 | 看垃圾郵件；員工多時要在 Supabase 設定寄信服務（見 deploy.md） |
| 出貨說庫存不足 | 可能還沒品管合格、已過期，或客戶要求的剩餘效期不夠 |
| 不能領料 | 進料還沒檢驗合格 |
| 畫面出現紅色「沒有權限…」 | 這個人的角色沒有這個功能的編輯權限 |
| 單據改不了 | 已關帳的日期，或單據已經結束 / 已出貨 |
| 備份 | 開發者 → 備份還原（本機版請定期備份；雲端版 Supabase Pro 每天自動備份） |
